# ตรวจสอบเพิ่ม–แก้ไข–ลบทั้งระบบ · 4 พฤศจิกายน 2569

รอบนี้ตรวจโค้ดร่วมกับการรัน server actions, ฐานข้อมูล PostgreSQL จำลอง และหน้าจอจริงในเบราว์เซอร์ ใช้ข้อมูลโรงเรียนจำลองทั้งหมด ไม่ได้เพิ่ม แก้ไข หรือลบข้อมูลโรงเรียนจริง

## ขอบเขตและผลตรวจ

- รายการฟังก์ชันที่อาจเปลี่ยนข้อมูลจาก AST: 230 จุด
- คำสั่งเขียนตารางที่ระบุชื่อโดยตรง: 202 จุด; โครงสร้างจาก migrations 55 ตาราง
- ไม่พบชื่อคอลัมน์ที่แกะได้จาก AST หรือชื่อ RPC ที่ขาดจาก migrations ในขอบเขตที่ตัวตรวจอ่านได้
- ชุดทดสอบผ่านทั้งหมด 133 สคริปต์: unit/ฐานข้อมูลจำลอง 107 และเบราว์เซอร์ 26 (ใช้ผลการทดสอบซ้ำล่าสุดหลังแก้ไข)
- TypeScript ทั้งโครงการผ่าน หลังแก้ข้อผิดพลาดเดิม 36 จุด เปิดตรวจ TypeScript ใน production build ตามปกติแล้ว
- การ build บน Windows: Turbopack ไม่จบขั้น compile ในช่วงตรวจ จึงเริ่มตรวจซ้ำด้วย Webpack; ตรวจผล build ของ deployment แยกผ่าน Vercel หลัง push

จำนวน AST เป็นรายการตรวจโค้ด ไม่ใช่จำนวนฟังก์ชันที่ทดสอบครบทุกเส้นทาง และไม่ใช่เปอร์เซ็นต์ความครอบคลุมของการทดสอบ ชื่อฟิลด์ที่สร้างแบบ dynamic, Storage และผลข้างเคียงของบริการภายนอกต้องตรวจแยก

## ขอบเขตที่ยังไม่ยืนยันบนบริการจริง

- ไม่ได้กดเพิ่ม–ลบข้อมูลจริงของทุกโรงเรียน จึงไม่ใช่การรับประกันว่าไม่มีบั๊กในทุกข้อมูลหรือทุกลำดับการใช้งาน
- Storage/Auth/Google Drive กรณีขัดข้องใช้ตัวจำลอง ไม่ได้ส่งไฟล์/ลบไฟล์จริงหรือทดสอบต่ออายุ OAuth ของผู้ใช้ทุกบัญชี
- SGS ใช้หน้าและข้อมูลจำลอง ไม่ได้ส่งคะแนนเข้าระบบ SGS จริง
- การประเมินค่าหลักและเกณฑ์เพิ่มเติมยังเป็นการเขียนสองตารางแยกกัน หากครั้งที่สองล้มเหลวค่าหลักอาจบันทึกแล้ว รอบนี้แก้การแจ้งผลและทดสอบการบันทึกซ้ำ ไม่ได้เปลี่ยนเป็น transaction เดียว
- การล้างการตั้งค่าโรงเรียนยังเป็นการทำงานหลาย batch ไม่ใช่ transaction เดียว หาก batch หลังล้มเหลวจะคืนจำนวนที่ลบไปแล้ว และยังต้องระวังกรณีโรงเรียนเริ่มมีผู้ใช้ระหว่างการตรวจและการล้าง
- การลบไฟล์ใหม่เพื่อชดเชยเมื่อบันทึก URL ล้มเหลวเป็น best effort หาก Storage ขัดข้องพร้อมกันอาจเหลือไฟล์ใหม่ที่ไม่ได้ใช้งาน แต่ไฟล์เดิมไม่ถูกเขียนทับ

## ทำซ้ำ

```powershell
npm run audit:crud
npm run test:crud-unit
npm run test:crud-ui
npx tsc --noEmit --pretty false
npm run build
```

ชุดทดสอบใช้ fixture และ network guard เพื่อไม่ให้คำสั่ง Node ไปเรียกฐานข้อมูลจริง ชุดเบราว์เซอร์ใช้หน้า localhost และโปรไฟล์ทดสอบแยกจากบัญชีผู้ใช้
