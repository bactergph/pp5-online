# จัดตารางบนเครื่องผู้ใช้

เส้นทาง `/schedules/device` ใช้สิทธิ์เข้าใช้งานและโฆษณาตามระบบเดิม ส่วนข้อมูลครู ห้อง วิชา กิจกรรม คาบไม่ว่าง และตารางเรียนของ workspace นี้เก็บใน IndexedDB ของเบราว์เซอร์ (`pp5-schedule-device`, store `snapshots`, key `free-plan`) ไม่บันทึกตารางหรือฉบับร่างเข้า Supabase โดยอัตโนมัติ

โหมดสมาชิกฟรีจำกัดรายชื่อครูสูงสุด **25 คน** ใช้รายชื่อร่วมกันทั้งสองภาคเรียน ตรวจทั้งการเพิ่มรายชื่อ การวาง Excel การนำเข้ารายวิชาที่สร้างครูใหม่ การนำเข้าไฟล์สำรองทั้งสองภาค และการสร้าง/ยืนยันฉบับร่าง หากข้อมูลเดิมเกินโควตาจะคงข้อมูลทั้งหมดให้สำรองหรือทยอยลดรายชื่อได้ แต่ยังจัดตารางไม่ได้จนเหลือไม่เกิน 25 คน ข้อจำกัดนี้ไม่ใช้กับบัญชี Pro หรือสมาชิกประเภทโรงเรียน

## ขั้นตอน

ใช้ CSS และ presentation components ร่วมกับตัวปกติ: `WizardPeriodEditor`, `LessonPatternPicker`, `ActivityAssignmentFields`, `ScheduleReviewStep`, และ `ScheduleGridTable` โดยข้อมูลและ event handlers ของโหมดนี้เป็น local ทั้งหมด

1. วันและเวลา: สูงสุด 8 คาบ พักกลางวันไม่ใช่คาบสอน
2. กำหนดชั้น/ห้อง
3. กำหนดครู (เพิ่มรายชื่อหรือวางจาก Excel)
4. รายวิชา (เพิ่มเองหรือวางตารางจาก Excel)
5. กิจกรรม: หลายห้องและทีมครูหลายคน กิจกรรมที่ไม่ระบุวันนำไปจัดอัตโนมัติ
6. ภาระสอน/คาบล็อก: ครู คาบต่อสัปดาห์ รูปแบบคาบ และสถานที่ร่วม
7. ตรวจ → สร้างฉบับร่าง → ตรวจตาราง → ยืนยันบันทึกลงเครื่อง

ตัวคำนวณใช้ `schedule-device.worker.ts` และ solver ชุดเดียวกับระบบตารางปกติ มี independent verification ก่อนรายงานว่าสำเร็จ ข้อมูลห้องนอกขอบเขตยังใช้ตรวจครูและสถานที่ชน กิจกรรมร่วมต้องพร้อมกันทุกห้องที่เกี่ยวข้อง

## ความคงทนของข้อมูล

- โหลดข้อมูลเก่ารูปแบบครูกิจกรรมคนเดียวได้ โดยแปลงเป็นทีมครูและอนุมานจำนวนคาบจากวันเดิม
- บันทึกลง IndexedDB ตามลำดับ รอ transaction complete ก่อนแจ้งว่าบันทึกแล้ว
- เปรียบเทียบ saved revision ใน transaction ป้องกันแท็บเก่าเขียนทับการแก้จากแท็บอื่น
- ตรวจ snapshot และข้อมูลที่เก็บล่าสุดอีกครั้งก่อนยืนยันฉบับร่าง
- เมื่อพื้นที่เก็บข้อมูลเต็ม/ถูกปิดกั้น จะแจ้งข้อผิดพลาด ไม่แจ้งว่าบันทึกสำเร็จ
- ดาวน์โหลดไฟล์ JSON และนำกลับเข้าได้ โดยตรวจรูปแบบและยืนยันก่อนแทนข้อมูลทั้งสองภาคเรียน
- การล้างข้อมูลเว็บไซต์ เปลี่ยนเบราว์เซอร์ หรือเปลี่ยนอุปกรณ์ไม่ได้พาข้อมูลไปด้วย ต้องใช้ไฟล์สำรอง

## ขอบเขตออฟไลน์

หลังเปิดหน้าและโหลดโค้ดแล้ว ข้อมูลและการจัดตารางไม่ต้องเรียก backend และทดสอบคำนวณ/ทิ้งร่างขณะตัดเครือข่ายได้ ส่วนการเปิดเว็บไซต์ใหม่ การเข้าสู่ระบบ และการอ่านสถานะสมาชิกยังใช้ระบบออนไลน์เดิม ไม่ได้เพิ่ม service worker หรือรับรองว่าเปิดเว็บใหม่ขณะออฟไลน์ได้

การอัปโหลดข้อมูลจากเครื่องเป็นความสามารถแยกของระบบเดิม โหมดนี้ไม่เรียกอัปโหลดโดยอัตโนมัติ
