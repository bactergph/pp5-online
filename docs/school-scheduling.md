# ระบบจัดตารางเรียนทั้งโรงเรียน

ก่อนเผยแพร่โค้ด ให้รัน `supabase/migrations/053_school_schedule_solver.sql` ใน Supabase SQL Editor ไฟล์นี้เพิ่มกิจกรรมในตารางเรียนและการบันทึกแบบ transaction โดยไม่จัดหรือเปลี่ยนตารางจริงให้เอง

## การใช้งาน

1. กำหนดรายวิชา ชั่วโมงต่อปี และครูในเมนูจัดครูเข้าสอนให้ครบ
2. เปิดจัดการตารางเรียน เลือกปีและห้อง แล้วเปิดส่วนกิจกรรมพัฒนาผู้เรียน เลือกกิจกรรม ครู และคาบต่อสัปดาห์ กิจกรรมที่ไม่ได้จัดทุกสัปดาห์ตั้งเป็น 0 ได้
3. เลือกวิชาหรือกิจกรรมลงช่องที่ต้องการ กดล็อกเพื่อเก็บคาบนั้นระหว่างจัดอัตโนมัติ ล็อกช่องว่างได้เพื่อกันเวลาไว้
4. กดจัดอัตโนมัติห้องนี้หรือทั้งโรงเรียน ค่าเริ่มต้นเติมช่องว่าง หากเลือก “จัดคาบที่ไม่ล็อกใหม่” ระบบจะคำนวณใหม่ครบก่อนแทนตารางเดิม
5. หากจัดไม่ได้ ระบบจะแจ้งสาเหตุและไม่เปลี่ยนตารางเดิม เช่น ครูสอนเกิน 30 คาบ คาบห้องเกิน 30 ครูไม่ครบ หรือคาบที่ล็อกชนกัน ห้องที่ยังไม่มีรายวิชา/กิจกรรมจะถูกข้ามพร้อมแจ้งชื่อห้อง

ตารางสอน ภาระงาน ตรวจความขัดแย้ง สอนแทน และส่งออกตาราง รวมกิจกรรมด้วย การคัดลอกตารางจับคู่รายวิชาหรือกิจกรรมเดียวกันและรักษาคาบปลายทางที่ล็อก หากจับคู่ไม่ได้หรือครูชนกันจะไม่บันทึก

ตารางเป็นรายปี จันทร์–ศุกร์ วันละ 6 คาบ โควต้ารายวิชาใช้ชั่วโมงต่อปีหาร 40 และปัดเป็นจำนวนเต็มอย่างน้อยหนึ่งคาบตามระบบเดิม กิจกรรมใช้จำนวนคาบที่กำหนด ครูหนึ่งคนสอนได้หนึ่งห้องในแต่ละคาบ การจัดอัตโนมัติค้นหาแบบมีขีดจำกัดเวลา จึงอาจขอให้ลดคาบที่ล็อกเมื่อเงื่อนไขซับซ้อนมาก

## การตรวจสอบ

`npm run test:schedules` ทดสอบตัวจัดตาราง การจัดใหม่/คัดลอก/ล็อก/สิทธิ์ และ PostgreSQL จำลองด้วย PGlite รวมการ rollback ข้อมูล สถานะตารางที่เปลี่ยนระหว่างทำงาน เวลาพักเที่ยง และสอนแทน ไม่ติดต่อฐานข้อมูลจริง

`npm run build` ตรวจการสร้างเว็บ การตรวจ TypeScript ต้องรัน `npx tsc --noEmit` แยก เพราะค่าเดิมของโปรเจกต์ตั้ง `ignoreBuildErrors: true`
