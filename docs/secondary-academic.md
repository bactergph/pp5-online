# งานวัดผลมัธยมศึกษา

ใช้โครงสร้างรายวิชาโรงเรียนเซกา (ข้อมูลกลาง ม.1–ม.6 ใน data/seka-secondary-subjects.json) เป็นกรณีอ้างอิง โครงสร้างนี้เป็นต้นแบบของรายวิชาและหน่วยกิต ไม่ได้อ้างว่าเป็นสำเนาแบบฟอร์มกระดาษเฉพาะของโรงเรียน

## เข้าใช้งาน

วัดและประเมินผล → งานวัดผลมัธยม → คะแนนรายภาค

- /evaluation/secondary: ส่งต่อไปหน้าคะแนนมัธยม
- /scores/secondary: คะแนนของห้องมัธยมเท่านั้น
- /attendance/secondary: เวลาเรียนรายวิชา แยกห้อง วิชา ปี และภาคเรียน
- /evaluation/secondary/{activities,character,reading,competency}: ประเมินรายภาค
- /reports/secondary/pp5: ปพ.5 รายวิชาตามภาคเรียน
- /reports/secondary/pp6: ปพ.6 พร้อมผลและหน่วยกิตรายภาค

รองรับ URL ที่มีรหัสโรงเรียนนำหน้า เช่น /seka/evaluation/secondary โรงเรียนมัธยมเห็นเมนูมัธยมโดยตรง โรงเรียนประถม/ขยายโอกาสยังใช้เมนูเดิมได้และมีทางเข้ามัธยมแยกให้

## กติกาคะแนน

ตัดเกรดมัธยมทั้งภาคเรียนที่ 1 และ 2 จากคะแนนและคะแนนเต็มของภาคนั้น ไม่บวกคะแนนสองภาคเป็นรายวิชาเดียว การบันทึกคำนวณคะแนนรวมและเกรดซ้ำฝั่งเซิร์ฟเวอร์จากคะแนนย่อย ไม่เชื่อเกรดหรือยอดรวมที่ส่งจากเบราว์เซอร์

ใช้เกณฑ์แปดระดับเดิมของระบบ 80/75/70/65/60/55/50 และผล ร/มส/มผ ไม่แปลงผลพิเศษเป็นเกรด 0 คะแนนที่ยังว่างไม่ถือว่าได้ศูนย์

GPA รายภาค = ผลรวม (เกรด × หน่วยกิต) ÷ หน่วยกิตของรายวิชาที่มีผลเป็นตัวเลข รวมวิชาที่ได้ 0 ในตัวหาร กิจกรรมไม่นำมารวม GPA ในรุ่นนี้ หากมีผลที่ยังไม่ครบ ร/มส หรือวิชาไม่กำหนดหน่วยกิต จะแสดงรอสรุป ไม่ออกรายงาน GPA ที่ดูเสมือนครบแล้ว แสดงทศนิยมสองตำแหน่งแบบตัดเศษ จัดอันดับเฉพาะผู้มีผลครบและใช้ GPA รายภาค

ยังไม่ใช่ระบบ GPA สะสมข้ามปีหรือระเบียน ปพ.1

## การเก็บข้อมูล

- ใช้บุคลากร นักเรียน ปีการศึกษา และห้องของโรงเรียนเดิม
- รายวิชามัธยมใช้ class_subjects.semester = 1/2 ส่วนข้อมูลเก่าที่เป็น 0 ยังคงมีคะแนนสองภาคแยกกันด้วย scores.term
- คะแนนใหม่ของมัธยมเก็บ year_total = null และผูกกับ student_id + class_subject_id + term
- ไม่เขียนทับคะแนนประถมหรือเปลี่ยนข้อมูลกลาง
- กิจกรรมมัธยมเก็บใน evaluation_custom_scores โดย kind=activities และ term=1/2 ทั้งรายการมาตรฐานและรายการเพิ่มของโรงเรียน ข้อมูลกิจกรรมรายปีใน activities_evaluation และค่ารายปี term=0 ไม่ถูกย้ายหรือแก้ไขอัตโนมัติ
- คุณลักษณะ การอ่าน และสมรรถนะใช้ข้อมูลรายภาคเดิมของห้อง พร้อมเกณฑ์ตามช่วงชั้น
- ไม่ต้องเพิ่ม migration ในการติดตั้งรุ่นนี้

สิทธิ์ครูผู้สอน ครูประจำชั้น สิทธิ์แพ็กเกจ การปิดกรอกคะแนน และคะแนนที่ลงนามแล้วใช้การตรวจสิทธิ์เดิม เพิ่มการตรวจว่าปี ห้อง และภาคเรียนตรงกับรายวิชา

## เอกสาร

ปพ.5 ใช้ตัวสร้างรายวิชามัธยมเดิม พร้อมข้อมูลเกรดรายภาคที่แก้ไขแล้ว ปพ.6 มีตัวสร้างแยกจากแบบประถม แสดงรายวิชา หน่วยกิต คะแนน เกรด GPA การประเมินและลายเซ็น แสดงภาค 1/2 แยกตารางเมื่อเลือกทั้งสองภาค มีการแบ่งหน้าเมื่อวิชามาก ไม่ลดขนาดตัวอักษรจนอ่านยาก

ลายเซ็นของ ปพ.6 มัธยมดึงแยกภาคเรียน แม้พิมพ์ทั้งสองภาคในไฟล์เดียวกัน ไม่ใช้ลายเซ็นของภาคหนึ่งแทนอีกภาค

พรีวิวปกติใช้พิกัดจากตัวสร้าง PDF เดียวกัน ตัวปรับแบบรายปีของประถมไม่แสดงใน ปพ.6 มัธยม

## ตรวจสอบ

npm run test:secondary-academic

กรณีสำคัญ: รายวิชาเซกาครบหกระดับ หน่วยกิต 0.5/1/1.5/2 เกรดแยกภาค ผลพิเศษ/คะแนนว่าง GPA ที่มีเกรด 0 หน่วยกิตไม่ครบ คะแนนรวมที่เบราว์เซอร์ส่งไม่ตรง ผลกิจกรรมสองภาคและรายปีเดิม Excel สิทธิ์ครู/ห้อง/ล็อกคะแนน UI มือถือและเดสก์ท็อป และ PDF จริง

ชุดทดสอบใช้ข้อมูลนักเรียนจำลอง ไม่บันทึกคะแนนจริงของเซกาหรือโรงเรียนอื่น
