# ตารางสอนแทนแบบรายวัน

ใช้หน้าจอเดียวกันใน `/schedules/substitute` และ `/schedules/device/substitute` โดยตัวออนไลน์บันทึกผ่าน server action ส่วนตัวฟรีบันทึกเฉพาะข้อมูลวันนั้นลงอุปกรณ์ ไม่มีการเปลี่ยนตารางเรียนหลักหรือภาคเรียนอื่น

## การใช้งาน

1. เลือกปี ภาคเรียน และวันที่
2. เลือกครูที่ลาหลายคนแล้วนำเข้าคาบพร้อมกัน รายการเดิมและครูสอนแทนที่กำหนดไว้จะคงอยู่ ไม่สร้างคู่ครู–ห้อง–คาบซ้ำ
3. เพิ่มรายการเอง หรือแก้ครูเจ้าของคาบ ห้อง วิชา คาบ ประเภทการลา และหมายเหตุได้ กรองดูรายการทีละคนหรือดูทั้งหมด
4. รายชื่อครูสอนแทนเรียงครูที่ว่างก่อน รายการที่ไม่ว่างยังเลือกได้ โดยแสดงคาบสอน กิจกรรม คาบล็อก รายการลา และสอนแทนที่ซ้ำกับร่างชุดเดียวกัน
5. กดบันทึกทั้งหมด หากมีรายการไม่ว่างจะเปิดรายละเอียดให้ยืนยันก่อน การเพิ่ม แก้ไข และลบจะบันทึกพร้อมกัน ผู้ใช้ยกเลิกร่างเพื่อกลับไปใช้ข้อมูลที่บันทึกไว้ได้
6. ด้านล่างสรุปครูที่มาสอนแทนจากข้อมูลที่บันทึกแล้ว แสดงว่าแทนครูใด วิชา/ห้องใด กี่รายการ กี่ช่วงคาบ และเวลาสอนจริง การดูแลหลายห้องในคาบเดียวกันนับเวลาครั้งเดียว

ครูเจ้าของคาบไม่สามารถสอนแทนตนเองได้ การอนุญาตให้เลือกครูที่ไม่ว่างเป็นการยืนยันของผู้จัดตาราง ไม่ได้ทำให้ภาระเดิมถูกยกเลิก

## การตรวจและจัดเก็บ

- ออนไลน์ใช้ migration `094_substitute_roster.sql`: เพิ่มข้อมูลยืนยันข้อขัดกัน ผู้ยืนยัน และเวลา; RPC สำหรับ CRUD ทั้งวันจำกัดสิทธิ์ที่ `service_role`
- ตรวจ snapshot ตารางเรียน/แผน/คาบล็อก/รายการสอนแทนภายใต้ school/year lock และตรวจรายการเดิมก่อนเขียน ป้องกันเขียนทับข้อมูลที่ผู้อื่นแก้
- ตรวจครู ห้อง ปี ภาคเรียน รายวิชา คาบซ้ำ และการสอนแทนตนเอง ข้อมูลที่ขัด scope ยืนยันข้ามไม่ได้
- เซิร์ฟเวอร์คำนวณเหตุผลใหม่ เปรียบเทียบกับเหตุผลที่ผู้ใช้ยืนยัน หากข้อมูลเวลาว่างเปลี่ยนต้องตรวจและยืนยันใหม่
- ตัวฟรีตรวจแบบเดียวกันในคิวเขียนของเครื่อง และแจ้งสำเร็จหลัง storage ตอบรับเท่านั้น ความล้มเหลวคงข้อมูลเดิมและร่างไว้
- การแก้ไขเก็บ ID และวันที่สร้างรายการเดิมไว้ PDF แสดงเครื่องหมายในหมายเหตุเมื่อมีการยืนยันสอนแทนทั้งที่ไม่ว่าง รายละเอียดเต็มเก็บไว้ในระบบ

## แนวทางอ้างอิง

ศึกษารูปแบบการแสดงเหตุผลครูไม่ว่างและการบันทึกคำตอบเป็นชุดจาก [WebUntis: solution view](https://help.untis.at/hc/en-150/articles/360010595900-How-can-I-solve-open-substituions) และ [feature overview](https://help.untis.at/hc/en-150/articles/360011117639-Substitution-Planning-Feature-Overview) โดยปรับเป็นขั้นตอนของจารย์เสก ไม่อ้างว่ามีทุกความสามารถเหมือนระบบอ้างอิง

## ทดสอบ

`npm run test:schedule-substitutes` ครอบคลุมเหตุผลไม่ว่าง การยืนยันสด การรวมเวลา SQL transaction/rollback/สิทธิ์/วันสร้างเดิม และหน้าจอร่วมของ Free/online ด้วยข้อมูลจำลองครูลา 5 คน รวม 10 คาบ ความกว้าง 320–1440px การทดสอบ SQL ใช้ PostgreSQL ผ่าน PGlite; การทดสอบ UI ใช้ตัวจัดเก็บ local จริงตาม service contract ไม่ใช้ข้อมูลโรงเรียนจริง
