# เปิด–ปิดห้องในงานจัดตาราง

การปิดชั้นหรือลดจำนวนห้องในขั้น 1 เปลี่ยนสถานะใช้งาน ไม่ลบห้องจริง

- ออนไลน์ใช้ `classrooms.schedule_enabled` ตัวฟรีใช้ `rooms[].enabled` โดยข้อมูลเดิมที่ไม่มีสถานะถือว่าเปิดอยู่
- สถานะห้องใช้ร่วมกันทั้งสองภาคเรียนของปีนั้น ห้องที่ปิดไม่รวมในรายวิชา ภาระสอน กิจกรรม ตารางครู การตรวจชน ตัวจัดตาราง และรายการพิมพ์
- ห้อง รายวิชา กฎการสอน กิจกรรม คาบล็อก และตารางเดิมยังเก็บไว้ รวมถึงไฟล์สำรองตัวฟรี
- เพิ่มจำนวนห้องกลับมาใช้ ID ตามลำดับห้องเดิมและคืนชื่อเดิม สร้าง ID ใหม่เฉพาะจำนวนที่เกินจากห้องที่เคยมี
- การบันทึกฉบับร่างหรือล้างตารางแตะเฉพาะห้องที่เปิด ข้อมูลห้องที่ปิดต้องไม่ถูกลบหรือปลดล็อก
- ไม่เปลี่ยนข้อมูลนักเรียน คะแนน หรือธุรการชั้นเรียน สถานะนี้ใช้กับงานจัดตารางเท่านั้น
- กลุ่มที่มีห้องปิดอยู่เก็บสมาชิกที่ปิดไว้ด้วย หากจะเปลี่ยนเวลา/รูปแบบของกลุ่มร่วม ต้องเปิดสมาชิกให้ครบก่อน เพื่อไม่แก้ข้อมูลที่เก็บไว้โดยไม่ตั้งใจ
- การเปิดกลับคืนข้อมูลเดิม หากระหว่างนั้นเปลี่ยนเวลาเรียนหรือคาบของครู การตรวจเงื่อนไขจะแจ้งข้อขัดแย้งให้แก้ก่อนจัดใหม่

## ฐานข้อมูล

ติดตั้ง `106_schedule_room_visibility.sql` ก่อนเผยแพร่โค้ด สคริปต์เพิ่มสถานะเริ่มต้นเปิดทุกห้อง ไม่ลบหรือย้ายข้อมูลเดิม และติดตั้งซ้ำได้

`save_timetable_classrooms` ตรวจสิทธิ์จาก server action ตรวจ snapshot โรงเรียน/ปี โควตาห้อง และบันทึกสถานะกับชื่อห้องทั้งสองเทอมใน transaction เดียว RPC และตัวช่วยที่เก็บข้อมูลปิดไม่เปิดให้ผู้ใช้เรียกตรง

ตัวตรวจเดิมอ่าน config ที่กรองห้องปิดผ่าน `schedule_room_plans` ส่วน config จริงรักษาข้อมูลที่ปิดผ่าน trigger การเขียนตารางยังใช้ CAS/lock/tenant/pattern/clock guards เดิม แต่จำกัดการลบและการเปรียบเทียบไว้ที่ห้องเปิด

## การตรวจสอบ

- `node scripts/test-schedule-room-visibility.cjs` — ตัวฟรี: ปิดห้องที่มีข้อมูล สร้างฉบับร่าง บันทึก ล้าง เปิดกลับ ไฟล์สำรอง และ write failure
- `node scripts/test-schedule-room-visibility-db.cjs` — PostgreSQL จำลอง: ติดตั้งซ้ำ การคงคาบล็อก CAS โควตา การแยกโรงเรียน ทีมกิจกรรม และการคืนข้อมูล
- `node scripts/test-schedule-room-visibility-ui.mjs` — หน้าจอจริง 320/390/1440px: ปิดชั้น ลด/เพิ่มห้อง คืนชื่อและ ID เดิม ทั้งสองโหมด
- TypeScript และชุด regression ตารางเรียน/สอนที่เกี่ยวข้อง
