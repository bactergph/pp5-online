# เลือกวิชาจากตารางครู

ปัญหาเดิม: เมื่อมี `profiles` ในเวลาเรียน หน้าล็อกคาบซ่อนปุ่มเลือกวิชา และหน้าตารางสอนเปลี่ยนเป็นอ่านอย่างเดียว แม้ผู้ใช้มีสิทธิ์แก้ไข

ปรับหน้าตารางครูและส่วนล็อกคาบที่ใช้ร่วมกันทั้งฟรีและออนไลน์:

- แตะช่องว่างแล้วเลือกวิชา/ห้องและบันทึกได้จากหน้าต่างเดียว ยังมีปุ่มล็อกคาบว่าง
- แสดงแกนเวลาจริงรวมทุกช่วงชั้นและกิจกรรมครู เก็บหมายเลขคาบของแต่ละห้องแยกจากหมายเลขช่วงที่แสดง
- ตัวเลือกวิชาต้องตรงเวลาเรียนของห้อง ไม่ใช่คาบพัก ไม่ชนคาบ/กิจกรรม/คาบล็อกของห้อง และยังมีคาบคงเหลือ
- เปลี่ยน/ลบ/ปลดล็อกวิชาเดิมใช้ห้องและหมายเลขคาบต้นทางจริง ถ้าช่วงที่กดทับหลายคาบ ให้เลือกคาบจริงก่อน
- การล็อกคาบว่างยังใช้คาบหลักของโรงเรียนตาม API เดิม ช่วงเวลาที่มีเฉพาะบางระดับเลือกลงวิชาได้ แต่ไม่ส่งหมายเลขช่วงแสดงผลไปเป็นคาบหลัก
- กิจกรรมนักเรียนและกิจกรรมครูยังแก้ผ่านเมนูกิจกรรม ไม่ถูกแทนที่ด้วยรายวิชา
- ผู้ที่ไม่มีสิทธิ์แก้ไขยังดูตารางอย่างเดียว

ตรวจด้วย `test-schedule-teacher-cell-options.cjs` และ `test-teacher-cell-picker-ui.mjs`: เวลาพักต่างระดับ, หมายเลขช่วงแสดงผลต่างจากคาบจริง, ห้องไม่ว่าง, คาบเต็ม, การเพิ่ม/เปลี่ยน/ลบ/ปลดล็อก, PLC, การบันทึกล้มเหลว, ตารางห้องตรงกับตารางครู, ทั้งฟรีและโปร และหน้าจอมือถือ/เดสก์ท็อป

ไม่เปลี่ยนโครงสร้างฐานข้อมูลหรือข้อมูลตารางเดิม
