# เช็กชื่อโฮมรูมมัธยม

เมนูหลักใต้หน้าหลัก: เช็กชื่อโฮมรูม — /attendance/homeroom รองรับรหัสโรงเรียนนำหน้า เช่น /seka/attendance/homeroom

โรงเรียนมัธยมและโรงเรียนขยายโอกาสที่มีชั้น ม.1–ม.6 เห็นทางเข้าระดับหลัก ไม่อยู่ภายในกลุ่มธุรการที่ถูกซ่อนในมัธยม ประถมที่ไม่มีชั้นมัธยมยังใช้เมนูเดิม

เลือกปี ห้อง ภาคเรียน และเดือน บันทึกมา ลา ป่วย ขาด และช่องว่าง พร้อมสรุปรายเดือน ส่งออกและพิมพ์ด้วยตัวสร้างเอกสารเวลาเรียนรายวันเดิม

ใช้ข้อมูล daily_attendance เดิมของห้อง ไม่มีการคัดลอกหรือล้างข้อมูลเดิม และไม่เปลี่ยน hourly_attendance ซึ่งเป็นการเช็กชื่อรายวิชา วันอนาคตยังไม่เติมมาเองตามกติกาปัจจุบัน

ครูประจำชั้นทั้งคนที่ 1 และ 2 เข้าห้องที่ตนรับผิดชอบได้ แม้ไม่ได้รับมอบหมายรายวิชาในห้องนั้น ผู้ดูแล/วิชาการเข้าถึงตามสิทธิ์เดิม ผู้อำนวยการดูอย่างเดียว และขอบเขตห้องประจำชั้นของแพ็กเกจส่วนตัวยังใช้ตามเดิม
