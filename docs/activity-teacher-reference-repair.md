# แก้การบันทึกครูลงกิจกรรมเมื่อมีรหัสครูเดิมค้าง

กรณีบุคลากรถูกลบ แต่รหัสยังอยู่ใน `schedule_plans.config.activityGroups` ตัวตรวจฐานข้อมูลจะตรวจทุกทีมในภาคเรียนนั้นและแจ้ง “ครูผู้รับผิดชอบไม่ถูกต้อง” แม้กำลังแก้กิจกรรมอีกทีมด้วยครูที่มีอยู่จริง

หน้า “กิจกรรม” จะแจ้งจำนวนรายชื่อที่ไม่อยู่ในบุคลากรที่พร้อมใช้งาน พร้อมปุ่ม **ปรับปรุงรายชื่อครูกิจกรรม** เมื่อผู้ใช้ยืนยัน ระบบนำรหัสที่ใช้ไม่ได้ออกจากทีมและรายการครูที่เลือก จากนั้นผู้ใช้เลือกครูปัจจุบันให้ทีมที่ขาดได้ การปรับปรุงนี้ไม่ลบบุคลากร รายวิชา ห้อง กิจกรรม คาบ หรือสถานะล็อก

แบบออนไลน์ใช้ RPC `repair_schedule_activity_teachers` ซึ่งตรวจสิทธิ์ผ่าน server action ตรวจโรงเรียน/ปี/ภาคเรียนและ snapshot ก่อนเขียนในธุรกรรมเดียว แบบฟรีบันทึกเฉพาะภาคเรียนที่เลือกและรองรับ IndexedDB write failure

Migration `104_activity_teacher_references.sql` ไม่ซ่อมข้อมูลโรงเรียนใดโดยอัตโนมัติ การซ่อมข้อมูลเดิมเกิดเมื่อผู้ใช้กดยืนยันเท่านั้น และมี trigger เก็บกวาดรหัสจากทีม/รายการครูที่เลือกเมื่อมีการลบบุคลากรในอนาคต เพื่อไม่ให้เหลือ dangling reference

ชุดทดสอบสร้างอาการเดิมในฐานข้อมูลจำลองก่อนซ่อม ยืนยันว่าบันทึกครูร่วมกิจกรรมผ่านหลังซ่อม โดยคาบและล็อกเดิมครบ ตรวจ stale snapshot/โรงเรียนอื่น/สิทธิ์ RPC/ค่า null การลบบุคลากรหลังติดตั้ง และหน้าจอจริงทั้งการยกเลิกและยืนยันที่ความกว้าง 360/390/1440 พิกเซล
