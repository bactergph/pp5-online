# เวลาเรียนแยกประถม–มัธยม

โรงเรียนขยายโอกาสเปิดตัวเลือก **แยกเวลาประถม–มัธยม** ได้ที่เมนู **เวลาคาบเรียน** หรือขั้นที่ 1 ของการเตรียมตาราง ทั้งแบบฟรีบนอุปกรณ์และแบบออนไลน์

1. เปิดตัวเลือกแยกระดับ
2. เลือก **ประถม ป.1–ป.6** แล้วกำหนดพักหลังคาบและเวลาเริ่ม–สิ้นสุด
3. เลือก **มัธยม ม.1–ม.6** แล้วตั้งเวลาอีกชุด เช่น ประถมพัก 11:30–12:30 น. และมัธยมพัก 12:30–13:30 น.
4. บันทึกเวลา แล้วกลับไปตรวจและสร้างฉบับร่างตามปกติ

ทุกห้องของระดับนั้นใช้เวลาชุดเดียวกันโดยอัตโนมัติ ระดับอื่นใช้ชุดค่าเริ่มต้น จำนวนคาบต่อวันของสองระดับต้องเท่ากัน (1–8 คาบ) แต่เวลาเริ่ม–สิ้นสุดและตำแหน่งพักต่างกันได้ หากต้องการเปลี่ยนจำนวนคาบ ให้กลับไปใช้เวลาชุดเดียวก่อน แล้วเปิดแยกระดับอีกครั้ง

เวลาคาบเป็นการตั้งค่าร่วมของโรงเรียน การบันทึกจะตรวจตารางเดิมทุกภาคเรียนและปีการศึกษา หากทำให้ครูหรือสถานที่ชน คาบคู่ข้ามพัก หรือกลุ่มสอนรวมมีเวลาไม่ตรงกัน จะปฏิเสธทั้งชุดและคงข้อมูลเดิม

คาบไม่ว่างของครูอ้างอิงแท็บ **ค่าเริ่มต้น / เวลาครูไม่ว่าง** ระบบเทียบช่วงดังกล่าวกับเวลาเรียนจริงของแต่ละห้อง หน้าล็อกคาบครูแสดงรายการที่ทับเวลาจริง ส่วนการเปลี่ยนรายวิชาในโรงเรียนที่แยกเวลาให้ทำผ่านตารางเรียนรายห้อง

## ผลต่อส่วนอื่น

- การจัดอัตโนมัติและการบันทึกตรวจเวลาเริ่ม–สิ้นสุดจริง ครูจึงสอนคาบเลขเดียวกันต่างระดับได้เมื่อเวลาต่างกัน แต่ไม่สามารถสอนช่วงเวลาทับกันแม้เลขคาบต่างกัน
- คาบคู่ใช้เวลาของระดับตนเองและไม่ข้ามพัก
- สอนรวมและกิจกรรมรวมต้องมีเวลาเริ่ม–สิ้นสุดตรงกันครบทุกห้อง
- ตารางเรียนและ PDF รายห้องแสดงพักตามระดับ สามารถพิมพ์หลายระดับในไฟล์เดียวโดยใช้เวลาประจำแต่ละหน้า
- ตารางสอนครูที่ข้ามระดับแสดงคอลัมน์ตามช่วงเวลาจริง จึงอาจมีคอลัมน์มากกว่าตารางเรียนของหนึ่งห้อง
- รายการสอนแทนและ PDF ใช้เวลาของห้อง ส่วนเอกสารสอนแทนยังแยกจากตารางปกติ
- ไฟล์สำรองแบบฟรีเก็บการตั้งค่าสองระดับไปด้วย โดยใช้รูปแบบไฟล์เดิม

## การติดตั้งและทดสอบ

ใช้ migration `103_schedule_period_profiles.sql` เพิ่มคอลัมน์ metadata และปรับตัวตรวจเวลาในธุรกรรมเดิม ไม่มีการเปิดใช้แยกระดับหรือเปลี่ยนตารางของโรงเรียนใดโดยอัตโนมัติ

```text
npm run test:schedule-period-profiles
```

ชุดเฉพาะฟีเจอร์ทดสอบการจัดทั้งโรงเรียน การตรวจชนจากเวลาจริง คาบคู่ ล็อกคาบว่าง ธุรกรรมบันทึก/ย้อนกลับฐานข้อมูล หน้าตั้งเวลาสองรูปแบบที่ความกว้าง 360/390/768/1440 พิกเซล การเก็บข้อมูลทั้งสองภาคเรียน และเวลาใน PDF ตารางเรียน/ครู/สอนแทน
