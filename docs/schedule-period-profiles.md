# เวลาเรียนสามช่วงชั้นและกิจกรรมครู

ใช้ร่วมกันทั้งตัวฟรีบนอุปกรณ์และตัวออนไลน์/โปร ขั้นตอนยังมี 7 ขั้น แต่เริ่มจาก **1 กำหนดชั้น/ห้อง → 2 วันและเวลา → 3 ครู → 4 กิจกรรม → 5 รายวิชา → 6 ภาระสอน/ล็อกคาบ → 7 ตรวจและจัดตาราง**

## ตั้งค่าชั้นและเวลา

- เลือกอนุบาล อ.1–อ.3, ประถม ป.1–ป.6 และมัธยม ม.1–ม.6 ได้ในโรงเรียนเดียวกัน กำหนดจำนวนห้องและชื่อห้องเองได้
- ขั้น 2 แสดงแท็บเฉพาะช่วงชั้นที่เปิดสอน ทุกห้องในช่วงชั้นเดียวกันใช้ชุดเวลานั้น
- แต่ละชุดมี 1–8 ช่วงเรียนและช่วงพักหลายช่วงได้ เช่น อาหารว่าง พักกลางวัน และนอนพัก รวมสูงสุด 24 ช่วง จำนวนคาบและเวลาไม่ต้องเท่ากันระหว่างช่วงชั้น
- มีตัวอย่างเวลาอนุบาลให้เริ่มปรับ การนอนพักเป็นเวลาพักนักเรียน หากครูต้องดูแล ให้ระบุครูและเวลาที่แท็บกิจกรรมครู
- วันเรียนของนักเรียนยังเป็นวันร่วมของโรงเรียน ส่วนวันทำกิจกรรมครูเลือกแยกได้
- ตัวเลือกขั้นสูง “เวลาครูไม่ว่าง / ค่าเริ่มต้น” เป็นชุดเวลาอ้างอิงล็อกครูเดิม หากช่วงชั้นยังไม่มีชุดเฉพาะจะใช้เวลานี้

ข้อมูลเดิมไม่ถูกเปลี่ยนเวลาอัตโนมัติ ชุดเวลาที่เคยมีเพียงประถม/มัธยมยังอ่านได้ การเพิ่ม/ลบช่วงเวลาแสดงผลเฉพาะร่างจนกดบันทึก และจะถูกตรวจเทียบตารางเดิมก่อนบันทึกจริง ออนไลน์ตรวจทุกปี/ภาคเรียน ส่วนตัวฟรีตรวจสองภาคเรียนของปีที่กำลังแก้

## ครูข้ามช่วงชั้น

ตัวจัดตาราง ตรวจเงื่อนไข บันทึก ล็อกคาบ และสอนแทนใช้เวลาเริ่ม–สิ้นสุดจริง คาบหมายเลขเดียวกันต่างช่วงชั้นอาจไม่ใช่เวลาเดียวกัน ส่วนคาบเลขต่างกันอาจทับกันได้ คาบคู่ต้องต่อเนื่องและไม่ข้ามช่วงพักของห้องนั้น สอนรวมหรือกิจกรรมร่วมต้องเริ่ม–จบตรงกันทุกห้อง

เมื่อแยกเวลา การเปลี่ยนรายวิชารายคาบให้ทำผ่านตารางห้องเรียน/ล็อกคาบเรียน เพื่อระบุห้องและชุดเวลาให้ชัดเจน ตารางล็อกครูใช้เวลาอ้างอิงหลักและแสดงคาบที่ทับเวลาจริง

## กิจกรรมครู

ขั้น 4 แยก **กิจกรรมนักเรียน / กิจกรรมครู** เพิ่ม แก้ไข และลบ PLC ประชุม เวรดูแลเด็ก ฯลฯ ได้ ระบุชื่อ วันทำซ้ำ เวลาแบบ 24 ชั่วโมง และผู้เข้าร่วมหลายคนได้ เช่น พุธ/พฤหัสบดี 15:30–16:30

- เวลากิจกรรมไม่จำเป็นต้องอยู่ในคาบเรียน และไม่เพิ่มคาบหรือข้อมูลรายวิชาของเด็ก
- ครูที่เข้าร่วมจะไม่ถูกจัดรายวิชาทับกิจกรรม รวมกรณีทับกันบางส่วนหรืออยู่ระหว่างพักของช่วงชั้นอื่น
- หากมีคาบเดิมทับอยู่ จะบอกครู วัน เวลา และรายวิชา ให้ปรับกิจกรรมหรือย้ายคาบก่อน ระบบไม่ย้ายคาบเดิมเอง
- กิจกรรมครูเก็บแยกตามปี/ภาคเรียน ลบกิจกรรมแล้วคืนเวลาครู ไม่ลบรายวิชา
- ภาระสอนยังนับเป็นคาบ สรุปนาทีกิจกรรมครูแยกในหมายเหตุ
- ไฟล์สำรองตัวฟรีเก็บข้อมูลนี้ด้วย และตรวจรายชื่อครูก่อนนำเข้า การลบบุคลากรล้างรหัสครูจากกิจกรรม หากไม่เหลือผู้เข้าร่วมจะนำรายการนั้นออก

## ดูตารางและ PDF

ตารางเรียนและ PDF รายห้องใช้เวลา/ช่วงพักของระดับนั้น ตารางสอนครูรวมช่วงเวลาจริงและกิจกรรมครู มือถือแสดงรายการรายวันเพื่ออ่านเวลาได้ชัด กิจกรรมครูไม่ปรากฏใน PDF นักเรียน

PDF ครูที่มีมากกว่า 10 ช่วงเวลารวมใช้รายการวัน–เวลา–วิชา/กิจกรรม แทนการบีบคอลัมน์จนอ่านไม่ออก หากรายการมากจะขึ้นหน้าต่อพร้อมหัวตาราง ลายเซ็นอยู่ท้ายรายการ รายการสอนแทนยังเป็นเอกสารแยกจากตารางปกติ

## การติดตั้งและทดสอบ

ใช้ migration 103, 104 และ **105_multiband_teacher_activities.sql** ตามลำดับ 105 ขยายช่วงพักและตัวตรวจข้อมูล โดยใช้ config ของ schedule_plans เดิม ไม่มีการแปลงข้อมูลโรงเรียนเมื่อรัน migration รักษา CAS, สิทธิ์โรงเรียน, คาบล็อก และธุรกรรมบันทึกเดิม

```text
npm run test:schedule-multiband
npx tsc --noEmit
```

ชุดเฉพาะตรวจตัวจัดสามช่วงชั้นที่เวลาเหลื่อมกัน, จำนวนคาบไม่เท่ากัน, ช่วงพักหลายช่วง, กิจกรรมครู, การสำรอง/กู้คืน, สรุปภาระสอน, PDF ภาษาไทย และฐานข้อมูลทดสอบ PGlite รวม stale write/rollback/การติดตั้งซ้ำ/สิทธิ์ RPC นอกจากนี้ทดสอบหน้าจอจริงทั้งสองโหมดที่ 320/390/768/1440 พิกเซล การนำเข้าครู/รายวิชา ล็อกคาบ และเส้นทางฟรีบน IndexedDB/Web Worker โดยไม่เขียนข้อมูลโรงเรียนจริง
