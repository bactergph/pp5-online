# จารย์เสก → SGS

ส่วนขยาย Chrome ของจารย์เสก เขียนขึ้นใหม่สำหรับเตรียม ตรวจ และเติมคะแนนทั้งชุดลงหน้า SGS โดยประมวลผลในเครื่องครู ไม่มี API key และไม่รับรหัสผ่าน SGS

## ติดตั้งครั้งแรก

1. แตกไฟล์ `jarnsek-sgs-extension.zip` ในโฟลเดอร์ที่เก็บไว้ใช้งานต่อได้
2. เปิด Chrome บนคอมพิวเตอร์ ไปที่ `chrome://extensions`
3. เปิด **โหมดนักพัฒนา** แล้วกด **โหลดส่วนขยายที่แตกไฟล์แล้ว**
4. เลือกโฟลเดอร์ที่มี `manifest.json` แล้วปักหมุดส่วนขยาย **จารย์เสก → SGS**

รุ่นนี้ติดตั้งด้วยไฟล์ ZIP ยังไม่ได้เผยแพร่ผ่าน Chrome Web Store และยังต้องตรวจการบันทึกกับ SGS จริงก่อนใช้งานเต็มรูปแบบ ไม่ใช่ผลิตภัณฑ์ของ SGS หรือ สพฐ.

## ส่งจากจารย์เสก (แนะนำ)

1. เมนูคะแนน เลือกปี ห้อง วิชา และภาคเรียน กด **ส่งคะแนนเข้า SGS**
2. เลือกช่องคะแนน แล้วดาวน์โหลด JSON หรือคัดลอกข้อมูล นักเรียนต้องมีเลขประจำตัวนักเรียนจริงในเมนูนักเรียน
3. เข้าสู่ SGS ด้วยบัญชีครูตามปกติ เปิดรายวิชาและห้องที่ตรงกัน แสดงนักเรียนครบ และเปิดคอลัมน์ที่จะรับคะแนน
4. กดส่วนขยาย เลือกไฟล์หรือวางข้อมูล กดอ่านข้อมูล
5. ตรวจคอลัมน์เลขประจำตัว แล้วเลือกช่องปลายทาง SGS ให้ตรงกับคะแนนแต่ละช่อง ตรวจคะแนนเต็มด้วย
6. ยืนยันปี ห้อง วิชา หากต้องแทนที่คะแนนเดิมให้เลือกอนุญาต กดตรวจคะแนน แล้วเติมทั้งชุด
7. ปิดตัวช่วยแล้ว **บันทึกด้วยปุ่มของ SGS** รอให้ระบบเสร็จ โหลดหน้าใหม่ เปิดตัวช่วย กด **ตรวจคะแนนหลังโหลดหน้าใหม่**

ข้อความเติมสำเร็จหมายถึงใส่ค่าลงหน้าเว็บแล้ว การตรวจหลังโหลดใหม่จะเปรียบเทียบเฉพาะช่องที่เติมและอ่านได้ในหน้าเดิม ไม่ใช่การรับรองผลอนุมัติคะแนนหรือการปิดงานวัดผลของ SGS

## วางจาก Excel

กดส่วนขยายบนหน้าคะแนนเพื่อเปิดใช้งานตัวช่วยในแท็บนั้น ปิดตัวช่วย คลิกช่องแรกของนักเรียนคนแรกที่จะเติม แล้ววางคะแนนหลายช่อง ตัวช่วยจะเปิดหน้าตรวจให้เอง

- คัดลอกเฉพาะตัวเลขคะแนน ไม่รวมหัวตาราง ชื่อ หรือรหัสนักเรียน
- ลำดับรายชื่อต้องตรงกับ SGS ทุกคน โหมดนี้ไม่ได้จับคู่นักเรียนจาก Excel ด้วยรหัส
- จำนวนแถวต้องตรงกับนักเรียนที่เหลือในหน้า จำนวนคอลัมน์ต้องเท่ากับช่องที่เปิดแก้ไขตั้งแต่ช่องเริ่มต้นในแต่ละแถว
- ช่องว่างต้นทางจะข้ามและคงคะแนนเดิม ศูนย์คือคะแนน 0
- เลือกคอลัมน์เลขประจำตัวใน SGS เพื่อบันทึกรายการตรวจหลังโหลดหน้าใหม่ได้

## ขอบเขต

- เปิดจากปุ่มส่วนขยายเท่านั้น รองรับหน้าบันทึกคะแนน HTTPS บน `sgs.bopp-obec.info` และโฮสต์ `sgs` ตามด้วยตัวเลขในโดเมนเดียวกัน
- รองรับตาราง HTML ที่แสดงเลขประจำตัวในเซลล์และช่องคะแนนแบบ `field_input`, `inputscore`, `inputscore2` ไม่เดารหัสจากชื่อหรือเลขที่
- แสดงนักเรียนสูงสุด 300 คนต่อหน้าและคะแนนต้นทางสูงสุด 24 ช่อง
- ไม่กดบันทึก SGS อัตโนมัติ ไม่แก้ฐานข้อมูลโดยตรง และไม่ยกเลิกคะแนนเดิมใน SGS ให้เอง
- ถ้าโครงสร้าง SGS ไม่ตรง ระบบหยุดพร้อมแจ้งเหตุผล ไม่วางแบบคาดเดา
- หากใช้งานร่วมกับส่วนขยายเติมคะแนนอื่น ควรปิดตัวอื่นก่อนเพื่อไม่ให้ดักการวางซ้ำกัน

## ข้อมูลส่วนบุคคล

ไม่มีการส่งคะแนนไปเซิร์ฟเวอร์ของจารย์เสกหรือบุคคลที่สาม ไม่มี telemetry ไม่มีโค้ดโหลดจากระยะไกล ไฟล์คะแนนที่ดาวน์โหลดมีข้อมูลนักเรียน ผู้ใช้เป็นผู้ดูแลไฟล์นั้น

ขอสิทธิ์ `activeTab` กับ `scripting` เพื่อเปิดตัวช่วยเมื่อผู้ใช้กดปุ่ม และ `storage` เพื่อเก็บเฉพาะรายการตรวจคะแนนชั่วคราวใน `chrome.storage.session` ของแท็บนั้น หมดอายุ 30 นาที ปิดแท็บจะลบ และ Chrome ล้าง session storage เมื่อปิดเบราว์เซอร์ ไม่มีการใช้ sync storage หรือเก็บรหัสผ่าน

ปุ่มล้างรายการตรวจลบเฉพาะข้อมูลชั่วคราว ไม่ลบหรือย้อนคะแนนใน SGS
